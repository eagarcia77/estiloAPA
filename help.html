Centro de ayuda de EstiloAPA

Guía práctica para editar documentos y aplicar APA 7.

Guía de la versión 3.4.9 · Auditoría en desarrollo

1. Comenzar

  1. Abra Document Setup & Advanced Options.
  2. Seleccione o arrastre un archivo compatible (DOCX, PDF, TXT, MD o HTML).
  3. Pulse Abrir documento seleccionado si el archivo no se abre automáticamente.
  4. Revise el resultado en el editor central y corrija cualquier elemento que no se haya importado correctamente.
  5. Guarde una copia mediante las opciones de descarga.

La importación puede variar según el contenido y la estructura del archivo. Revise tablas, imágenes y referencias después de abrirlo. En archivos DOCX, las imágenes PNG, JPEG, GIF, WebP y BMP compatibles se intentan incorporar al editor como imágenes integradas. Revise las figuras y sus textos alternativos después de importar; algunos formatos especiales de Word pueden requerir revisión manual.

2. Editar y dar formato

Editor y herramientas de Word

Haga clic dentro de la hoja para modificar el texto. Utilice la cinta de herramientas disponible para títulos, párrafos, alineación, listas y tablas. Los controles disponibles pueden variar según la selección.

Aplicar APA 7

En las opciones avanzadas, revise la fuente, sangrías y demás preferencias. Use Reapply APA 7 para volver a aplicar el formato. Antes de hacerlo, guarde una copia si realizó cambios manuales importantes.

Reglas y sangrías

La regla horizontal ayuda a visualizar los márgenes y ajustar sangrías. Permanece al inicio del área del documento y se desplaza con el contenido para no cubrir los párrafos al bajar por el texto. Si la regla no coincide con los bordes de la hoja, compruebe el zoom y el ancho de la ventana. La alineación se encuentra en proceso de validación.

3. Revisar el documento

Citas, referencias y tablas APA 7

Abra APA 7 Review & Report y ejecute la revisión. El resultado es orientativo: compruebe las citas, las fuentes originales, las tablas, las figuras y la correspondencia entre citas y referencias. No suponga que una puntuación equivale a cumplimiento total.

Accesibilidad

Use el comprobador de accesibilidad cuando esté disponible. Revise textos alternativos de imágenes, encabezados y estructura de tablas. Las comprobaciones automáticas no sustituyen una revisión manual.

Asistente IA Gemini

Gemini es opcional. Seleccione el tipo de revisión y el contenido que desea enviar; lea y marque el consentimiento antes de solicitar sugerencias. Las sugerencias deben revisarse manualmente. La conexión segura por usuario está pendiente de activación y puede requerir una clave temporal del servidor. Nunca escriba una clave API de Google en la aplicación.

4. Exportar y solucionar problemas

Descargar Word o HTML

Utilice Download DOCX o Download HTML. Abra el archivo descargado para comprobar saltos de página, tablas, imágenes y sangrías antes de entregarlo.

El documento no abre o perdió formato

Compruebe que el archivo no esté dañado y que su extensión sea compatible. Intente importar una copia. Si el problema persiste, anote el tipo de archivo y el paso donde ocurre; evite compartir documentos con datos confidenciales.

Gemini muestra un error 502

Un error 502 suele indicar un problema de comunicación con el servidor. Espere e inténtelo nuevamente; si continúa, el administrador debe revisar el despliegue del servicio Cloudflare y sus registros.

5. Actualizaciones de la ayuda

Esta ayuda se mantiene junto con el código de EstiloAPA. Toda actualización que cambie el comportamiento visible, los controles, las opciones de exportación o la integración con IA debe actualizar esta guía y registrar el cambio en el historial de ayuda.
