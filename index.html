APA7 Academic Formatter

Formatea y edita módulos académicos, disertaciones doctorales y tesis de maestría; incorpora una barra de edición APA 7 y auditoría individual del formato de referencias.

v3.0

1. Cargar y ejecutar

Seleccione uno o varios documentos. Para comprobar que la aplicación funciona sin subir archivos, presione Probar ejemplo.

v3.0: añade un editor APA 7 dentro de la vista previa con encabezados nivel 1–5, alineación, sangrías, interlineado, tabla/figura APA, enlace, salto de página y presets para párrafos y referencias. La auditoría ahora evalúa individualmente el formato visible y la estructura bibliográfica de cada referencia.

2. Auditoría APA 7 y estructura

—

La puntuación es heurística. Además de citas, estructura y tablas, la auditoría de v3.0 revisa cada referencia: sangría francesa, doble espacio, orden alfabético, autor/fecha, DOI/URL y cursivas esperadas según el tipo probable de fuente.

  • Cargue uno o más archivos o presione “Probar ejemplo”.

Documento editable

3. Vista previa y exportación

Seleccione texto o coloque el cursor en un párrafo y use la barra APA 7 para editar el documento. Los cambios se mantienen en la vista previa y se sincronizan antes de exportar.
